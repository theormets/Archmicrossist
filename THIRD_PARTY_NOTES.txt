The RGB8 resizing code is an independent JavaScript implementation of separable bicubic convolution, with fixed-point coefficient rounding and pad geometry chosen for compatibility with Pillow 12 ImageOps.pad. Mathematical interpolation is implemented locally rather than using browser-dependent canvas scaling. Reference implementation documentation: https://github.com/python-pillow/Pillow/blob/12.0.0/src/libImaging/Resample.c and https://github.com/python-pillow/Pillow/blob/12.0.0/src/PIL/ImageOps.py . No Pillow source file or compiled library is bundled. ONNX Runtime Web 1.22.0 loads from its CDN; the existing verified model in the Space is reused.
